# Dice & Daring: a kid-friendly adventure game run by Claude

No rules to learn and no story to prepare. Claude is the Game Master.

## How to play

1. Gather the kids, grab one six-sided die each (optional; Claude can roll).
2. Open this repo in Claude Code and type: **"Let's play!"**
3. Read Claude's messages out loud and type what the kids want to do.
4. When you're done, say **"We're stopping for today."** Claude saves your
   progress so next time it picks up where you left off.

## What's inside

- `CLAUDE.md`: instructions that turn Claude into a kid-friendly Game Master
- `rules/RULES.md`: the entire rulebook (one page, a single die)
- `campaign/`: *The Lost Lanterns of Puddlebrook*, a 5-chapter adventure
- `heroes/`: the kids' characters get saved here
- `campaign/progress.md`: the save file

Useful things to say to Claude any time: "make it shorter", "make it simpler
for my 5-year-old", "we have 10 minutes left, wrap it up", "roll for us".
